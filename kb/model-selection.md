# Model Selection

- Select a model by task, quality target, latency, context length, modality, and cost.
- Use a smaller fast model for classification, routing, and routine extraction when evaluation results are acceptable.
- Use a stronger model for ambiguous reasoning, complex generation, or difficult multimodal tasks.
- Embedding models produce vectors for search and clustering; they do not generate normal chat answers.
- Confirm current model availability and limits in the product documentation or dashboard rather than assuming them.
