# Usage and Billing

- The dashboard is the source of truth for measured usage, remaining credit, invoices, and the active plan.
- Usage can differ between models and request types. Compare the same billing period and timezone.
- A support conversation cannot verify a live balance, charge, invoice, or refund without an authenticated billing tool.
- For a suspected duplicate charge or invoice dispute, collect the invoice or transaction reference and date, then hand the case to human support.
- Never request a complete card number, password, one-time code, or full API key.
